# Instruções para o Codex — Entrelinhas
Leia ROADMAP.md e docs/produto antes de trabalhar. Produto web gratuito em português, repositório público sem contribuições inicialmente, para iniciantes e intermediários em programação competitiva. Slogan: Existe aprendizado entre cada tentativa. Não é juiz online.
## Diretrizes
- Priorize evolução pessoal, privacidade por padrão, acessibilidade WCAG 2.2 AA como meta, gamificação saudável e recomendações explicáveis.
- Desenvolvimento individual com dogfooding; não exigir personas, entrevistas ou questionários externos.
- Trabalhe incrementalmente, preserve arquivos existentes, apresente plano antes de implementar e aguarde aprovação para avançar de etapa.
- Explique código, conceitos, alternativas e limitações. Execute testes possíveis e reporte resultados reais; não marque testes não executados como aprovados.
- Stack candidata: Java/Spring Boot, React/TypeScript, PostgreSQL, Tailwind, Recharts, JPA, Flyway, Spring Security, OpenAPI, Docker Compose, GitHub Actions. Monólito modular; Python para POCs. Não são decisões definitivas.
- Use adaptadores para Codeforces e AtCoder; preserve dados originais, não equipare dificuldades, não infira causas de erros a partir de verdicts.
- Não versionar credenciais nem dados pessoais; não solicitar senhas externas; não fazer commits, pushes ou deploy sem autorização.
- Atualize ROADMAP.md conforme evidências. Etapa atual: POC01, código experimental fornecido, integração real pendente.
